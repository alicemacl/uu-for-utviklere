Del 4 · Konkrete grep i koden

Grep 6 og 7: ARIA og små gevinster

ARIA er bare for når HTML ikke holder. Første regel for ARIA er å ikke bruke ARIA når HTML kan gjøre jobben. Og noen av de minste grepene – som lang og prefers-reduced-motion – er blant de raskeste å fikse.

Huskeregel: Ingen ARIA er bedre enn dårlig ARIA.

role="button" er ikke nok

ARIA endrer bare hva skjermleseren sier – ikke hva elementet gjør. En <div role="button"> lover en knapp, men trenger fortsatt tabindex="0", tastaturhåndtering for Enter og mellomrom, fokusstil og logikk for deaktivert tilstand. Eller du kan bruke <button>.

Prøv: Tab til knappen. Hva skjer i «før»?

aria-hidden på noe som kan få fokus

aria-hidden="true" skjuler innholdet for skjermleseren, men ikke for tastaturet. Resultatet er en lenke du kan tabbe til, men som er stum.

Prøv: Tab til lenken med skjermleser på.

aria-label som overstyrer synlig tekst

aria-label erstatter teksten i elementet. Når den ikke stemmer med det som står på knappen, hører skjermleserbrukeren noe annet enn det andre ser – og talestyring («klikk Søk nå») virker ikke.

Prøv: Se på «Name» i Accessibility-fanen i DevTools for begge knappene.

Når ARIA er riktig: tilstand

HTML har ikke et eget element for alt. Et trekkspill trenger å fortelle om det er åpent eller lukket – da er aria-expanded på en ekte knapp riktig verktøy. (Og trenger du ikke full kontroll over utseendet, gir <details> og <summary> deg alt dette gratis.)

Prøv: Åpne og lukk med tastaturet. Lytt etter «sammenslått» og «utvidet».

Statusmeldinger med role="status"

En melding som dukker opp et annet sted på siden, ser du – men skjermleseren vet ikke at den kom. Et element med role="status" som finnes på siden fra start, blir lest opp når innholdet endres.

Prøv: Trykk «Lagre kladd» med skjermleser på.

lang på html-elementet

Malen fra Vite og Create React App har lang="en". Da leser skjermleseren norsk tekst med engelsk stemme. Riktig språk gir også riktig orddeling, stavekontroll og oversettelse. Bruk lang="en" på enkeltord eller avsnitt som faktisk er engelske.

Prøv: Les teksten i begge rammene med skjermleser. Hør på uttalen.

prefers-reduced-motion

Animasjoner som glir, spretter eller ruller kan gi svimmelhet og kvalme for personer med vestibulære plager. Mange har slått på «Reduser bevegelse» i operativsystemet – respekter det.

Prøv: DevTools → Rendering → «Emulate CSS media feature prefers-reduced-motion» → reduce. Eller slå det på i macOS (Tilgjengelighet → Skjerm) eller Windows (Animasjonseffekter av).

En sidetittel som sier noe

<title> er det første skjermleseren leser når siden lastes, og det som står i fanen og i historikken. «React App» i tolv faner hjelper ingen.
